## معرفی پوشه

این پوشه شامل نمونه‌برنامه‌ها و پروژه‌های آزمایشی برای میکروکنترلر **CH643** با استفاده از کتابخانه **ch32-hal** است.

## بردهای پشتیبانی‌شده

### CH643-Pico

این برد توسعه در مخزن [CH643-Pico در GitHub](https://github.com/WayneWu3/CH643-Pico) معرفی شده است.

- **میکروکنترلر:** CH643Q
- **LED:** متصل به پایه PB17

برای نمونه‌برنامه LED، پایه **PB17** را به‌صورت خروجی GPIO پیکربندی کرده و وضعیت آن را برای روشن و خاموش کردن LED تغییر دهید. قطبیت فعال LED (Active High یا Active Low) را با مدار واقعی برد تطبیق دهید.
