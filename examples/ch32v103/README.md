## معرفی پوشه

این پوشه شامل نمونه‌برنامه‌ها و پروژه‌های آزمایشی برای میکروکنترلر **CH32V103** با استفاده از کتابخانه **ch32-hal** است.

## بردهای پشتیبانی‌شده

### CH32V103C-R1 و CH32V103C-R0

این دو نسخه از برد دارای **PCB سبزرنگ** هستند.

### CH32V103R_R1

این نسخه از برد دارای **PCB مشکی‌رنگ** است.

رنگ PCB در اینجا برای تشخیص نسخه‌های سخت‌افزاری برد به کار رفته است. هنگام استفاده از نمونه‌برنامه‌ها، مدل دقیق برد و اتصالات واقعی پایه‌ها را با سخت‌افزار خود تطبیق دهید؛ این README تخصیص پایه‌های جانبی یا LED را برای این بردها مشخص نکرده است.

</div>
