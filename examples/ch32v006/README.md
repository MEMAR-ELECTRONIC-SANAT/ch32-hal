## معرفی و راهنمای نمونه‌برنامه‌های CH32V006

این پوشه شامل نمونه‌برنامه‌ها و پروژه‌های آزمایشی برای میکروکنترلر **CH32V006** با استفاده از کتابخانه `ch32-hal` است. اطلاعات برد توسعه و مشخصات هدف کامپایل در این بخش توضیح داده شده‌اند.

## برد توسعه

### CH32V006K8U6-EVT-R0

در برد توسعه `CH32V006K8U6-EVT-R0` برای استفاده از LED باید با یک سیم جامپر، پایه LED را به یکی از GPIOهای میکروکنترلر متصل کنید. بنابراین برخلاف بردهایی که LED به‌صورت ثابت به یک پایه متصل شده است، در این برد انتخاب GPIO به نحوه سیم‌کشی جامپر وابسته است.

## هدف کامپایل و افزونه‌های پردازنده

فایل هدف کامپایل پروژه [`riscv32emc-unknown-none-elf.json`](riscv32emc-unknown-none-elf.json) است. این فایل معماری هدف را برای ساخت برنامه‌های بدون سیستم‌عامل (bare-metal) مشخص می‌کند و افزونه `xwchc` را فعال می‌سازد.

افزونه `xwchc` دستورهای فشرده اختصاصی WCH برای بارگذاری و ذخیره‌سازی داده‌های بایتی و نیم‌کلمه‌ای را فراهم می‌کند. هسته `QingKe V2C` از این افزونه پشتیبانی می‌کند. برای بررسی جزئیات معماری و مجموعه دستورها به جدول ۱-۱ راهنمای هسته `QingKe V3` مراجعه کنید.

## نکات سخت‌افزاری و راه‌اندازی

- پیش از اجرای نمونه‌های GPIO، اتصال جامپر LED به پایه موردنظر را بررسی کنید.
- پایه انتخابی در برنامه باید با پایه‌ای که به‌صورت فیزیکی به LED متصل کرده‌اید یکسان باشد.
- فایل JSON هدف کامپایل را تغییر ندهید، مگر آنکه قصد استفاده از هدف پردازنده و تنظیمات سازگار دیگری را داشته باشید.

# CH32V006

## Boards

CH32V006K8U6-EVT-R0

- LED requires jumper wire to connect to any GPIO

## Target

[`riscv32emc-unknown-none-elf.json`](riscv32emc-unknown-none-elf.json) enables `xwchc`, WCH's compressed byte and halfword loads and stores. QingKe V2C implements the extension (QingKe V3 manual, table 1-1).
